プライバシーポリシー

このページは、本ソフトと公式サイトにおける情報の取り扱いを、利用規約・プライバシーポリシーの同じ正本から抜き出して掲載しています。内容や版は利用規約と共通です。

第7条（AI 機能について）

本ソフトには、AI 機能を含む版と含まない版があります。AI 機能が入っていない版では、本条は適用されません（AI タブが表示されず、AI を使う操作はすべて「この版では AI 機能は入っていません」と表示して実行されません）。お使いの版に AI 機能が入っているかどうかは、［ファイル］→［アプリ情報］→［ライセンス情報］でご確認ください（AI タブは設定で隠すこともできるため、タブの有無では見分けられません）。

AI 機能を含む版には、Claude（Anthropic PBC 提供）と連携する機能が含まれています。この機能を使う場合、次の点に同意したものとします。

  1. AI 機能は、利用者自身のパソコンに入っている Claude Code と、利用者自身の契約を通じて動きます。作者は AI の利用料を受け取っておらず、AI サービスを再販してもいません。

  2. AI 機能を使うと、機能に応じて、次の情報の全部または一部が、利用者の Claude Code を通じて外部の AI サービスへ送られます。

    • 利用者が入力した指示、この書類を開いてからの直近の会話、本ソフトに保存した覚え書き。
    • 利用者が貼り付けた画像と、その画像を一時的に置いたファイルの場所。
    • 開いている書類のファイル名・元のファイルの場所・ページ数・用紙の大きさ・現在のページ・選択しているページ・注釈の件数・未保存の変更があるかどうか。
    • 対象となる書類から取り出した文字、またはページを画像にしたもの。

    パソコンの中だけで完結するものではありません。本ソフトは、画面に、書類の文字を送ること、送る文字数、画像にするページ数など、その操作の主な送信内容を表示します。ただし、上記の案内情報、直近の会話および覚え書きの全文を、送信のたびに一つの一覧で表示するものではありません。利用者が送信または実行の操作を行ったときに送ります。通常の送り先は Anthropic 社ですが、実際の送り先とその取り扱いは、利用者の Claude Code の設定と、利用するサービスの契約・ポリシーに従います（Claude Code には接続先を変える設定があるため、送り先を1社に限って保証はできません）。作者が本ソフトについて負う責任は、第11条のとおりです。

  3. AI 機能で送られた内容を、作者が受け取ることはありません。内容は利用者の Claude Code から送り先のサービスへ直接送られ、作者はその中継をしておらず、見ることもできません。
  4. 機密書類・個人情報を含む書類に AI 機能を使うかどうかは、利用者の責任で判断してください。所属先に守秘義務がある場合は、事前に許可を得てください。
  5. AI の出力は誤ることがあります。AI が出した数値・要約・翻訳・読み取り結果は、必ず人が確かめてから使ってください。
  6. Anthropic 社の利用規約は、利用者が自分で守るものとします。Anthropic 社が送られた内容をどのように扱うかは、同社の規約・ポリシーによります。
  7. AI 機能は、Anthropic 社が提供する Claude Code の上で動いています。Claude Code の仕様変更・提供終了などにより、AI 機能が使えなくなることがあります。作者は、AI 機能が将来も使えることを保証しません（責任については第11条のとおりです）。
  8. AI 機能を使わなくても、本ソフトの他の機能は使えます。また、AI 機能は設定で切ることもできます。切った状態では、本ソフトの AI 機能から書類が送られることはありません。※ 利用者がご自分で起動した Claude Code や、ご自分で入れた別のスキルの通信までは、本ソフトの設定では止まりません。※ AI タブは設定で隠すこともできるため、タブが見えないこと＝AI 機能が入っていない版、とは限りません。搭載の有無と、設定による入り切りは、［ライセンス情報］で別々に確認できます。

第8条（データの取り扱い）

  1. 本ソフトは、ふつうの PDF の表示・編集の処理において、書類の中身を作者へ自動で送ることはありません。ただし、利用者が問い合わせに文章やファイルを添えて送った場合は、次項に書いたものが作者に届きます。AI 機能による書類内容の送信については、第7条のとおりです。

  2. 本ソフトの機能は、次の場合に外部と通信します。

    • 第7条の AI 機能を使ったとき。AI 機能が入っていない版・AI 機能を切った状態では、この通信は起こりません。
    • 更新の確認と、利用者が操作したときの更新ファイルの取得。問い合わせ先は配布元（GitHub）および配信に使われるサーバーです。このとき送られるのは通信に必要な情報だけで、書類の中身は送られません。※「1日に1回まで」は自動で確認を行う回数であって、通信が必ず1本だけという意味ではありません（取得や転送が伴うことがあります）。

    • 不具合の報告・ご要望の送信（利用者が自分の意思で送信ボタンを押したとき）。送るのは次のものだけです。

      • 利用者が書いた文章
      • 種類（不具合／要望など）と、調査に必要な環境情報（本ソフト・Windows・Electron・Chrome の版、パソコンの種類、画面の大きさ、開いている書類のページ数）。書類の名前は、この環境情報には含めません。
      • 利用者が自分で添えた画面写真・ファイル（貼り付け・落とし込み・選択したもの）。添えていなければ、何も送られません。
      • お名前・返信先として入力した内容（利用者が書いたときだけ）。メールアドレスとして読み取れる場合は、返信先にも使います。

      ※ お名前も返信先も書かずに送れます。ただし、本文や添えたものに含まれる情報は作者に届きます。また、受付サービスは、通信の処理や迷惑送信の防止のためにIP アドレスなどの通信情報を扱います。利用者が自分で添えないかぎり、書類の中身・ファイル名・利用者のお名前は送られません。★添付したものは作者に届きます。社外に出せない書類（客先の図面など）は添付しないようご注意ください。本ソフトは添付されたものの中身を確認しません。送信された内容は、受付システム（Cloudflare）およびメール送信サービス（Resend）を経由して作者に届きます。これらの事業者は、各社のポリシーに従って日本国外を含む地域で情報を処理することがあります。送信は任意で、送らなくても本ソフトの機能に違いはありません。

    • Web ページや HTML を PDF にする機能を使ったとき。指定したページのサイトのほか、HTML の中に書かれている外部の画像・書体・その他の部品の提供元や、スクリプトが指定する送り先へ通信することがあります。★手元の HTML ファイルや貼り付けた HTML でも、外部への参照や通信するスクリプトが含まれていれば通信が起こります（作者へは何も送られません）。外に出したくない内容を含む HTML は、外部参照を外してからお使いください。
    • ［応援］や本規約内のリンクなどから外部サイトを開いたとき。利用者がリンクを押した場合に限り、既定の Web ブラウザーがリンク先へ通信します。リンク先での情報の取り扱いは、そのサイトの規約・ポリシーに従います。

  3. 更新の確認は、配り方によって動きが違います。

    インストーラーで入れた版

    • 起動してしばらくすると、1日に1回まで、配布元へ「新しい版はあるか」だけを問い合わせます。確認できなかった場合（配布元に届かない・圏外など）も、次に試すのは翌日以降です（自動の問い合わせは、成功・失敗を問わず1日に1回までです）。利用者が［更新を確認］を押したときは、この回数に関係なくその場で確認します。
    • 新しい版があれば知らせます。落とすのも入れ替えるのも、利用者がボタンを押したときだけです。押さなければ何も起きません。

    zip で配った版

    • 調べ先は利用者が決めるもので、既定では設定されていません（設定するまで通信しません）。設定したあとも、いつでも止められます。
    • 新しい版の有無を知らせるだけで、この版が自分で更新を落としたり入れ替えたりすることはありません。

    Microsoft Store から入れた版

    • 配布と更新は Microsoft Store が取り扱います。更新の時期や自動更新の有無は、Store 側の設定・仕様に従います。上の2つの手順は、この版には当てはまりません。

    インストーラー版・zip 版では、利用者に断りなく中身が入れ替わることはありません。

  4. 本ソフトは、次の情報を、本ソフトのユーザーデータ、利用者が指定した保管フォルダー、または OS の一時フォルダーに保存します。

    • 表示や機能の設定、最近開いたファイルの場所、登録した印鑑・レシピ・マクロ、書類ごとの覚え書き、AI 機能の直近の会話など、次の起動で作業を続けるための情報。印鑑・レシピ・マクロと一部の設定は、更新後も引き継げるよう、利用者が指定した保管フォルダーにも保存されます。
    • 保存していない作業を戻すための作業の控え。控えには PDF の内容、注釈、ファイル名・元の場所、ページ数、保存できなかった理由などが含まれ、本ソフトのユーザーデータ内の `recover` フォルダーに保存されます。既定の保存期間は1日です。期限を過ぎた控えは、本ソフトの起動時または起動中の定期的な片付けで削除されます。そのため、期限を迎えた時刻ちょうどに削除されるとは限りません。残す日数と自動作成は、［ファイル］→［作業を再開］から開く［作業のバックアップ］画面で変更でき、同画面から個別または一括で削除できます。控えを開いても元ファイルへは書き込まず、未保存の作業として開きます。
    • PDF の変換・パスワード解除・OCR・AI に見せるページ画像・変更前後の確認などに使う作業用の一時ファイル。これらには書類の内容が含まれることがあり、OS の一時フォルダー内の `%TEMP%\PDF Studio` に置かれます。機能の終了時に削除するもののほか、1時間を過ぎたものを本ソフトの起動時および起動中の定期的な片付けで削除します。強制終了などで片付けられなかったものや、作成から1時間以内のものは、次回以降の片付けまで残ることがあります。
    • 更新の動作とエラーを確認するための `update.log`。`%LOCALAPPDATA%\PDF MARIN\update.log` に保存し、書類の内容は記録しません。
  5. 本ソフトは、前項の情報や更新ログを作者へ自動で送りません。保管フォルダーには、利用者がローカルのフォルダーのほか、ネットワーク上の場所（UNC パスを含みます）や OneDrive などの同期先を指定することもできます。利用者がそのような場所を選んだ場合や、利用者自身がバックアップソフト・同期ソフトを使っている場合は、それらの設定に従って別のパソコンやサービスへ複製されることがあります。

第9条（公式サイトについて）

  1. 本サイトは、GitHub Pages（GitHub 社のサービス）を利用して公開しています。
  2. 本サイトは、文字の表示に Google Fonts を使っています。そのため、ページを開くとGoogle のサーバーへ通信が発生し、IP アドレスなどが送られます。
  3. 作者は、本サイトに利用者を追跡する Cookie や、独自のアクセス解析を入れていません。GitHub Pages は、安全の確保のため、訪問者が GitHub にログインしているかどうかにかかわらずIP アドレスを記録します。Google Fonts などの提供者も、サービスの提供に必要な通信情報を各社のポリシーに従って扱います。
  4. 本サイトで利用者が情報を入力する場所は、不具合の報告・ご要望のフォームだけです。そこで送られるものは、第8条2項の「不具合の報告・ご要望の送信」と同じです。
  5. 本サイトの「応援する」ボタンの先は、Ko-fi という外部のサービスです。そこでの決済や個人情報の扱いは、Ko-fi および決済事業者（Stripe / PayPal）の規約・プライバシーポリシーに従います。
