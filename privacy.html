プライバシーポリシー

このページは、本ソフトウェア（以下「本ソフト」）および公式サイト（https://pdf-marin.github.io/ 、以下「本サイト」）が、利用者のどのような情報を、どのように取り扱うかをまとめたものです。あわせて利用規約もご覧ください。

1. 基本方針

  1. 本ソフトは、利用者が開いた書類・入力した文字・操作履歴・氏名などの個人情報を、作者へ送信しません。編集・墨消し・変換などの処理は、すべて利用者のパソコンの中だけで行われます。
  2. 本ソフトは、利用者の同意なく広告目的で情報を収集することはありません。

2. 本ソフトが外部と通信する場合

本ソフトが外部と通信するのは、次の4つの場合だけです。

  • AI 機能を使ったとき（AI 機能を含む版のみ。含まない版・機能を切った状態では通信は起こりません）。利用者自身の Claude Code を通じて、書類の中身（文字やページの絵）が Anthropic PBC へ送られます。本ソフトは送信前に必ず確認を表示します。送信された内容を作者が受け取ることはありません。
  • 更新の確認（新しい版が出ていないかを調べる機能）。問い合わせ先は配布元（GitHub、または Microsoft Store 版では Microsoft Store）です。通信に必要な情報だけが送られ、書類の中身は送られません。
  • 不具合の報告・ご要望の送信（利用者が自分の意思で送信ボタンを押したときだけ）。送るのは、利用者が書いた文章・種類（不具合／要望など）・本ソフトの版・OS の種類・利用者が自分で添えた画面写真やファイル・返信先メールアドレス（書いたときのみ）です。添えないかぎり、書類の中身・ファイル名・お名前は送られません。送信内容は受付システム（Cloudflare）とメール送信サービス（Resend）を経由して作者に届きます。
  • Web ページを PDF にする機能で、URL を指定したとき。指定したサイトへ、そのページを取りに行くための通信が発生します（作者へは何も送られません）。

3. Microsoft Store 版について

  1. Microsoft Store 経由でインストール・更新した場合、そのインストール・更新・決済（本ソフトは無償ですが）に関する情報は、Microsoft 社が自社のプライバシーに関する声明に従って取り扱います。作者はこれらの情報を受け取りません。
  2. Microsoft Store 版でも、本ソフト自体が行う通信は本ポリシー第2条のとおりで、変わりはありません。

4. 本ソフトのパソコン内での保存

設定・印鑑・よく使う操作（マクロ）などは、利用者のパソコンの中にだけ保存され、外部へ送られることはありません。

5. 公式サイトについて

  1. 本サイトは GitHub Pages（GitHub 社のサービス）で公開しています。
  2. 本サイトは文字の表示に Google Fonts を使っており、ページを開くと Google のサーバーへ通信が発生します（IP アドレスなどが送られます）。
  3. 本サイトは、Cookie やアクセス解析の仕組みを使っていません。
  4. 本サイトで利用者が情報を入力する場所は不具合の報告・ご要望のフォームだけで、送られる内容は第2条の「不具合の報告・ご要望の送信」と同じです。
  5. 「応援する」ボタンの先は Ko-fi という外部サービスです。決済・個人情報の扱いは Ko-fi および決済事業者（Stripe / PayPal）の規約・プライバシーポリシーに従います。

6. 未成年の利用について

本ソフトは、年齢を問わず利用できる内容です。利用者から年齢・生年月日などの個人情報を積極的に収集する機能はありません。

7. お問い合わせ

本ポリシーに関するご質問は、次のどちらからでも受け付けています。

  • 本サイトの報告フォーム（お名前は不要。返信先を書かなければ匿名で送れます）
  • 本ソフトの右上にある「改善要望・問い合わせ」
